# YouTube Smart Blocker for Kids — Privacy Policy

Last updated: June 2025

## Data Collection
This extension does not collect, transmit, or share any personal data.

## Data Storage
All filtering rules and settings are stored locally on your device 
using Chrome's built-in storage API. This data never leaves your browser.

## Permissions Used
- **storage**: To save your blocking rules and settings locally
- **tabs**: To apply rules across open YouTube tabs when settings change
- **contextMenus**: To add a right-click menu on YouTube pages
